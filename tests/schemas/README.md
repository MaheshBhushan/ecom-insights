# Power BI JSON schemas

`powerbi.json` pins the Microsoft JSON schemas used by the committed Power BI
project, including their referenced schemas. Keys retain the original schema
URLs. Tests resolve every reference locally and make no network requests.

Source: [Microsoft JSON schemas for Fabric](https://github.com/microsoft/json-schemas/tree/main/fabric).
The [Microsoft JSON schemas repository license](https://github.com/microsoft/json-schemas/blob/main/LICENSE)
applies to these schemas.
